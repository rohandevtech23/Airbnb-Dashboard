# 🏡 Airbnb Listings Analytics Dashboard | Power BI | Python | Excel

## 📌 Project Overview

The **Airbnb Listings Analytics Dashboard** is an interactive Power BI project designed to analyze Airbnb listing data and provide valuable insights into pricing, availability, customer reviews, property distribution, and host performance. The dashboard helps users understand market trends and supports data-driven decisions for hosts, property managers, and business analysts.

> **Dataset Source:** The dataset used in this project was downloaded from **Kaggle**.

---

# 🎯 Business Problem

The Airbnb marketplace contains thousands of property listings with different prices, locations, room types, and availability. Analyzing this large amount of data manually is challenging and time-consuming.

This dashboard simplifies the analysis by converting raw listing data into interactive visual reports that highlight important business metrics and trends.

---

# 🎯 Objectives

- Analyze Airbnb listings across different locations.
- Monitor pricing trends and average listing prices.
- Compare room types and property distribution.
- Analyze availability and occupancy patterns.
- Evaluate host performance.
- Build an interactive dashboard for quick business insights.
